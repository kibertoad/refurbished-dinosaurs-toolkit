# Changesets

The npm packages (`@scientific-method/executable-reader` and `@scientific-method/standard-checker`)
are versioned with [Changesets](https://github.com/changesets/changesets). A pull request that
changes one of them adds a changeset:

```sh
pnpm changeset
```

See [`docs/releasing.md`](../docs/releasing.md) for how releases are published.
