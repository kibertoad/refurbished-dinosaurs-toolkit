`imports` reads NE (16-bit Windows) executables with `sourceKind: "ne"`, as STATUS-44 of the documentation standard describes. It lists the import at every site an import's relocation record covers, walking the chain of each record whose additive flag is clear to `FFFF`, with segment, offset, source type, record, module and ordinal or name, and lists internal references and operating-system fixups apart. Iterated segments are expanded first. A chain that reaches `chainCap` sites without `FFFF` is listed as cut short, and a site outside the segment's data, a site that overlaps one already reached and a link onto another record's offset are listed as errors with the sites past them unknown. `expectedCounts` rejects the report when a segment's record or site count differs, `exporters` (hash-checked copies of the exporting modules) and `outsideTables` put names to ordinals with the table each came from, and a positive control site that maps to any other import rejects the report. The library exports `neImportReport` from `@scientific-method/executable-reader/ne-imports`. Other commands refuse `ne`, and the message `prepare` gives for an unsupported `sourceKind` now names it.
