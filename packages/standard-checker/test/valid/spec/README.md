# Example Game specification

## Scope

A minimal spec used to test the documentation standard check. It describes an
imaginary game, build BLD-EXAMPLE-1.0, with one format and one rule.

## Standard version

This spec follows version 1 of the
[documentation standard](https://dinorefurb.com/documentation-standard/).

## Areas

Areas are added to this list and never removed or renamed.

| Area | Covers |
|---|---|
| `SCORE` | The high-score table and how a score is counted. |
